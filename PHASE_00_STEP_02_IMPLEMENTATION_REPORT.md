## Technical Architecture & Component Mapping

### 1. `HttpBackendApiClient.kt` Design & Threading Strategy
- **Location**: [`core/src/main/java/com/sucharu/sucharupro/data/api/client/HttpBackendApiClient.kt`](file:///E:/App/Sucharu%20Pro/core/src/main/java/com/sucharu/sucharupro/data/api/client/HttpBackendApiClient.kt)
- **Interface Implemented**: `BackendApiClient`
- **Networking Stack**: Zero external networking third-party libraries added; built on top of Kotlin Standard Library `java.net.HttpURLConnection` with JSON serialization handled by `Gson`.
- **Threading Model**: All network operations are executed asynchronously off the main thread using `withContext(Dispatchers.IO)`.
- **Concurrency & Token Refresh**: Utilizes a thread-safe `Mutex` for single-flight token refresh execution. If multiple concurrent requests experience token expiration, only one thread executes the refresh API call while caller threads await the fresh token without redundant network trips.
- **Request Metadata**: Automatically injects standard system headers:
  - `Accept: application/json`
  - `Content-Type: application/json` (for POST/PUT/PATCH calls)
  - `Authorization: Bearer <token>` (when session token is present)
  - `X-Correlation-ID` (autogenerated UUID per request unless pre-specified)

### 2. Session Management & Token Storage Integration
- **Token Storage**: Accepts `AuthTokenStorage` (e.g. `EncryptedSharedPreferencesAuthTokenStorage`).
- **Authorization Flow**:
  - `login()`: Posts credentials to `/api/v1/auth/login`. On HTTP 200, stores the `token` and `refreshToken` securely via `tokenStorage.saveTokens()`, returning `ApiResult.Success(AuthTokenResponse)`.
  - `register()`: Posts registration DTO to `/api/v1/auth/register`. On HTTP 200/201, stores session tokens and returns `ApiResult.Success(AuthTokenResponse)`.
  - `refreshToken()`: Executes POST to `/api/v1/auth/refresh` using `refreshTokenMutex` single-flight lock. Updates stored tokens upon success.
  - `logout()`: Posts to `/api/v1/auth/logout` and clears stored tokens via `tokenStorage.clearTokens()`.

### 3. Base URL & Environment Resolution
- **Production Gateway Setup**: Modified `ProductionRuntimeComposition.createSessionManager()` to construct `HttpBackendApiClient(baseUrl = gatewayUrl, tokenStorage = tokenStorage)`.
- **Validation**: Strict pre-flight checks enforce that `gatewayUrl` is neither blank nor unconfigured (e.g., throwing `IllegalStateException` with clear error guidance if `SUCHARU_GATEWAY_URL` is omitted).

### 4. Error Mapping & Contract Fidelity
- **JSON Unwrapping**: Standardized response wrapper `ApiSuccessResponse<T>` unwraps payload data.
- **HTTP Status Code Mapping**:
  - `200..299` -> `ApiResult.Success(data)`
  - `400` -> `ApiResult.Error(ErrorCode.INVALID_INPUT, message)`
  - `401` -> `ApiResult.Error(ErrorCode.UNAUTHORIZED, message)`
  - `403` -> `ApiResult.Error(ErrorCode.FORBIDDEN, message)`
  - `404` -> `ApiResult.Error(ErrorCode.RESOURCE_NOT_FOUND, message)`
  - `409` -> `ApiResult.Error(ErrorCode.CONFLICT, message)`
  - `422` -> `ApiResult.Error(ErrorCode.UNPROCESSABLE_ENTITY, message)`
  - `500..599` -> `ApiResult.Error(ErrorCode.SERVER_ERROR, message)`
  - `SocketTimeoutException` / `IOException` -> `ApiResult.Error(ErrorCode.NETWORK_ERROR, message)`
