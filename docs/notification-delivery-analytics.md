# Notification Delivery Analytics

## Analytics per Channel
- **IN_APP, EMAIL, SMS, PUSH**:
  - Total Dispatched, Delivered, Failed, Retried, Suppressed.
  - Delivery Success Rate (%) and Failure Rate (%).
  - Average and P95 latency (ms).
  - Health threshold: <95% is `DEGRADED`, <80% is `CRITICAL`.
